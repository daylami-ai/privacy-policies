本利用規約（以下「本規約」）は、SOUL CODE Ω（以下「本アプリ」）の運営者（以下「当方」）が提供する本アプリの利用条件を定めるものです。利用者の皆さま（以下「ユーザー」）は、本規約に同意のうえ本アプリをご利用ください。

1. 適用範囲

本規約は、ユーザーと当方との間の本アプリの利用に関わる一切の関係に適用されます。本アプリの利用を開始した時点で、本規約に同意したものとみなします。

2. サービス内容

本アプリは、氏名・生年月日等から複数の占術を計算し、総合的な鑑定結果を表示する、エンターテインメント目的のアプリケーションです。当方は、ユーザーへの事前の通知なく、本アプリの内容を変更することがあります。

3. アプリ内課金

  • 本アプリには、有料コンテンツ（詳細鑑定の都度解放、およびフルレポートの買い切り）があります。価格はすべて税込で、購入画面に表示されます。
  • 購入の支払いは、Google Play の決済の仕組みを通じて処理されます。クレジットカード番号などの決済情報は Google が取り扱い、当方が取得・保持することはありません。
  • 購入後の返金については、Google Play の規定に従います。当方が個別に返金対応を行うことはありません。
  • 買い切り型の有料コンテンツ（フルレポート）は、購入時と同じ Google アカウントで再インストールした場合に、アプリ内の「購入の復元」から復元できます。

4. 広告

本アプリは、広告配信のために Google AdMob を利用しています。有料コンテンツを購入していない場合、無料の鑑定結果が表示される直前に広告が表示されます。広告に関する情報の取り扱いについては、プライバシーポリシーをご確認ください。
